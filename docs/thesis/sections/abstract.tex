Quantum Key Distribution (QKD) has emerged as a secure alternative to classical cryptographic algorithms like RSA, which are threatened by quantum computers. 

The goal is to design and implement an event-driven quantum network simulator capable of evaluating the performance of the E91. In order to achieve this, the simulator contains distance dependant fidelity degradation, dark counts , CHSH validation and classical postprocessing of the generated keys.

The simulator achieved an average CHSH value of 2.801, with identical source and destination keys across all runs. Eavesdropping collapsed the CHSH parameter to an average of 0.491, correctly triggering protocol termination

The simulator correctly reproduces the quantum behavior predicted by the E91 protocol and reliably detects eavesdropping via CHSH violation.
